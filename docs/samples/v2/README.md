# 개정 2 인계 샘플

2026-10-21 한 날짜를 저장소의 기존 자료에서 발췌한 예제다. 최신 시세가 아니다. 원본 ZIP 보관 예제가 아니라 FED-TEXT-2로 추출한 내용이다.

- `FED_*.rows.json`: 해당 테이블에 넣을 key/chunk_no/text 컬럼 값. H41은 key1=계열, key2=연도, key3=묶음. 금리는 key1=연도, key2=묶음. 레포는 key1=거래 ID, key2=묶음.
- `FED_*.text.tsv`: 논리 자료별 문자열을 복원한 뒤 순서대로 보여주는 읽기용 예제. M 행마다 새 논리 자료가 시작한다. 각 D 행의 날짜는 그대로 보존된다.
- `dashboard-response.sample.json`: 동일 날짜 자료의 기존 화면용 응답 예제. 한 날짜만 있으므로 기간 변화는 N/A가 정상이다. 품질 항목은 샘플 범위에 맞춘 최소 예제이며 운영에서는 전체 이력 validate 결과를 생성한다.
- `validate.cjs`: 샘플을 직접 읽어 UTF-8 바이트 제한·그룹/조각 순서·텍스트 복원과 원천별 주요 수치 및 기존 화면 계약을 확인한다.

실행: 저장소 루트에서 `node docs/samples/v2/validate.cjs`.

샘플의 2,000바이트 검사는 UTF-8 기준이다. 실제 적재 전에 사내 DB 문자셋으로 다시 확인한다. 샘플은 짧아서 대부분 한 조각이며, 7조각 경계와 다중바이트 경계는 사내 전체 자료 통합검사의 별도 항목이다. 원천의 상세 필드 전체를 보존하지 않으므로 원본 파일을 바이트 단위로 재생성할 수는 없다.
