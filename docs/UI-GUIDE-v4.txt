FED Balance Sheet v3 — 회사 운영 안내 개정 4

1. 입수 프로그램은 매일 07:15 KST에 6개 원천의 전체 사용 이력을 수집합니다.
   날짜 결합·단위 변환·순유동성 등 계산·검증을 끝내고 FED_SCREEN_DATA에만 저장합니다.
   원천별 DB 테이블은 만들지 않으며, 원본 파일은 임시 사용 후 정리합니다.

2. DB 조회 담당자는 FED_SCREEN_DATA의 정렬된 SELECT 결과 전체를 내부 프로그램으로 전달합니다.
   데이터 가공·JSON 작성·서버 개발을 맡지 않습니다.

3. 화면은 조각 번호·개수·검사값을 확인하고 문자열을 합쳐 JSON으로 해석합니다.
   최초 조회 완료 전에는 로딩 상태를 표시하고, 이전 번들 자료를 먼저 표시하지 않습니다.
   새로고침은 저장된 DB 자료를 다시 조회하며 원천 재수집을 실행하지 않습니다.
   갱신 실패 시 직전 정상 화면을 유지하고 오류를 알립니다.

4. HTML과 CSS·JavaScript·폰트 등 assets를 함께 배포합니다.
   현재 로컬 StartDashboard.cmd와 POST /api/refresh 동작은 회사 운영 연결과 다릅니다.

5. 상세 규격: fed-balance-sheet-v3-operations-v4.md 및 v3-implementation-handoff-v4.md.
   사내 DB·조회 통신 연결은 별도 구현 대상입니다. 기존 UI-GUIDE.txt는 변경하지 않고 보존합니다.
